## 対応済み（このブランチ）

- Account が「クラウド同期」と書いていたのをやめ、端末保存である旨に変更（1-1）
- 主要 UI・alert を `t` 経由に（ActionBar、Header、Profiles、依存モーダル、空状態、DL 結果）（1-2）
- ZIP 保存後に「Minecraft には入らない」と案内。部分失敗時は失敗名を列挙（1-3, 2-10）
- 選択 0 件では Check / Download を出さない（3-1）
- ヘッダーと左カラムに Profiles の実ボタン（3-3）
- 空状態に次の一手を書いた（3-4）
- 依存ボタンを盾アイコンの Check から Dependencies + グラフアイコンへ（3-5）
- 装飾アイコンの空 `alt`、`/mods/[id]` ギャラリー `key={item.url}`（4-1）

---

- アカウントログイン（Discord / NextAuth）を削除
- 永続化を localStorage から IndexedDB へ（初回は旧キーを移行）
- 検索バーに「フィルタのバージョン = ZIP のバージョン」の説明（3-2）
- CustomDialog の Tab フォーカストラップ（4-2 の一部）
- Service worker 失敗を debug log に出す（2-8）
